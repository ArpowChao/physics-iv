# 電磁學・學習筆記｜高中選修物理Ⅳ

[開啟 GitHub Pages 網站](https://arpowchao.github.io/physics-iv/)

依全華《選修物理Ⅳ》靜電學、電流磁效應、電磁感應三章編排。沿用 [波動與光學・學習筆記](https://github.com/ArpowChao/phy-wave-optics) 的首頁、章節側欄與導讀版面：先觀察現象，再讀概念與公式，最後做題檢核。

- **課程導讀**：12 節的目標、課本小標題、公式條件、例題與自我檢核。章末另有等電位線、電流天平、認識電磁波的探究導讀。
- **逐概念練習**：30 個概念，每個各有兩題、共 60 題。可在該節概念下展開作答，也可從「觀念練習」按章節挑選。點選後立即看解析，答對紀錄只存在目前瀏覽器。
- **電磁實驗室**：12 個 SVG 互動模擬；可調變因、即時讀值與重置。帶電質點、發電機與電磁波可播放、暫停或直接拖動進度。
- **2D／3D 工作臺**：6 組、24 種情境。2D 可切換 XY、XZ、YZ；3D 可用拖曳或方向鍵轉向。切換時使用同一組參數、播放進度與測量結果。12 節課程均有對應入口。
- **逐章練習卷**：每卷 12 題、100 分（單選 40、多選 20、三題題組 24、手寫 16）。多選每題恰有 2 或 3 個正確選項，整題全對才給分。手寫含繪圖、填充或計算，依所附規準自評。
- **教師用資料**：逐題有課本小標題、課綱對照、Bloom 層次與適用的第五學習階段探究能力；空白卷和解答可分開列印。段考範本、上次試題分析及額外繪圖規格未提供，本站採自訂題卷格式與程式繪製的向量圖。

來源為全華課本第 1–3 章、[108 自然科學領域課綱](https://stv.naer.edu.tw/data/course_outline/pta_18538_240851_60502.pdf)（加深加廣選修，印刷頁 42–43、47–48、195–196）與 Krathwohl 的修訂版 Bloom 分類等附件。教材、題目與圖為重新編寫；原始附件不隨網站發布。實驗是高中課程模型，各頁標示模型的適用條件或示意比例。

25 個工作臺情境預設以「引導觀察」開啟。先記下預測，再比較兩個只改一項條件的案例。證據表保留兩次讀值，兩案都觀察過後可展開參考解釋。「自由探索」可調整全部參數、拖曳測點及查看完整讀值。兩種方式各自保留目前操作狀態。

靜電場圖以穿過兩電荷連線的參考切面計數，每 1 nC 畫 2 條線。3D 可切換前後分層、只看前側和單一參考切面。沿軸剖面與電位地形分別標示電場與電位的零點，電位地形高度有顯示上限。接地空腔金屬球採同心球殼，分別以鏡像電荷計算腔內與球外的電場。 [OpenStax 電力線](https://openstax.org/books/university-physics-volume-2/pages/5-6-electric-field-lines) · [OpenStax 靜電平衡的導體](https://openstax.org/books/university-physics-volume-2/pages/6-4-conductors-in-electrostatic-equilibrium)

粒子加速器採非相對論模型。直線加速器依同步條件計算漂移管長度。工作臺預設顯示實驗裝置與運動，勾選「分析標註」可疊加向量和符號。極光採傾斜偶極地磁場，以 110 km 為比較折返高度的參考面。電子運動顯示導引中心，電子群模式的光幕示意高層大氣發光。海陸輪廓來自公開領域的 Natural Earth 資料。 [OpenStax 迴旋加速器](https://openstax.org/books/university-physics-volume-2/pages/11-7-applications-of-magnetic-forces-and-fields) · [Berkeley Lab 直線加速器](https://abc.lbl.gov/wallchart/chapters/11/3.html) · [NASA 極光說明](https://science.nasa.gov/sun/auroras/) · [Natural Earth 陸地輪廓](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/)。

必歐－沙伐工作臺的圖面、測點拖曳和讀值配置參考 [SAMN Physics 的必歐－沙伐模擬](https://samnphysics.github.io/physicssimulation/electromagnetism/biosavrit.html)。首頁字型由站內的 Outfit 與 Noto Sans TC 子集提供，授權文件見 `assets/fonts/`。

物理模型以全華課本為課程範圍，並對照 OpenStax 的 [必歐－沙伐定律](https://openstax.org/books/university-physics-volume-2/pages/12-1-the-biot-savart-law)及[動生電動勢](https://openstax.org/books/university-physics-volume-2/pages/13-3-motional-emf)。模擬在三維座標計算，再以可旋轉的正射投影顯示，不依賴 WebGL。有限導線省略外部回路，螺線管以同軸圓圈近似；畫面向量箭長不作量尺，量值以數字讀數為準。

## 在本機使用

直接開啟 `index.html`，或執行：

```sh
python -m http.server 8000
```

瀏覽 `http://localhost:8000/`。不需要登入、建置或下載外部字型及套件。作答與完成標記存在目前瀏覽器，不會傳到伺服器。

| 檔案 | 內容 |
| --- | --- |
| `data/course.js` | 三章導讀、公式、例題與課綱對照 |
| `data/concept-practice.js` | 各節的逐概念練習、Bloom 標記與解析 |
| `data/exams.js` | 三卷原創試題、詳解、配分與題目分類 |
| `data/workbench-lessons.js` | 各實驗的預測問題、單一變因比較、證據與解釋 |
| `assets/labs.js` | 互動模型、讀值、示意圖與題圖 |
| `assets/physics-models.js` | 三維向量、電位、磁力與感應的數值模型 |
| `assets/workbenches.js`、`assets/workbench-ui.js` | 工作臺情境、三維投影、圖表、相機與時間控制 |
| `assets/workbench-art.js`、`data/earth-land.js` | 裝置材質、粒子軌跡與極光視覺 |
| `assets/site.js` | 網頁導覽、實驗控制、練習與列印 |
| `assets/site.css` | 響應式排版與 A4 列印樣式 |
| `assets/learning-layout.css` | 沿用光學站的學習首頁、側欄、導讀與檢核樣式 |

GitHub Pages 以 `main` 分支根目錄發布。練習卷與互動實驗可用 `#practice/1`、`#labs/flux` 等網址直接開啟。

## 驗證

安裝 Playwright（`python -m pip install playwright` 和 `python -m playwright install chromium`），啟動本機伺服器後執行：

```sh
python scripts/check_site.py http://localhost:8000/
python scripts/check_workbenches.py http://localhost:8000/
node scripts/check_physics_models.js
```
